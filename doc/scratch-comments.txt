1. INTRODUCTION                               *scratch-comments-introduction*

Comment on any lines in any file, then copy the comments out as Markdown or
JSON to paste into an LLM or give to a person. Commented lines get a sign,
and |:CommentShow| shows the comment on the cursor line.

Comments live in the buffer. They go away when you close the buffer or clear
them.

Setup: >lua
    require("scratch_comments").setup()
<
Add your own mappings. See |scratch-comments-api| for examples.

2. COMMANDS                                       *scratch-comments-commands*

                                                                    *:Comment*
:[range]Comment         Comment on the current line, or on [range]. To comment
                        on a selection, select lines and type ":Comment",
                        which gives ":'<,'>Comment". If those exact lines
                        already have a comment, edit it.

                        A window opens in the middle of the screen: the lines
                        you are commenting on at the top, your comment below.
                        It opens in insert mode, and its title shows the mode
                        you are in. Write as many lines as you like, then
                        |:wq| to save. |:q| closes it if nothing changed, and
                        |:q!| throws your changes away. |CTRL-W_w| moves
                        between the two parts, or scroll them with the mouse.

                                                                *:CommentShow*
:CommentShow            Show the comment at the cursor in the same window,
                        read-only, with the lines it is on. If more than one
                        comment covers the line, asks which one. |:q| closes
                        it.

                                                                *:CommentEdit*
:CommentEdit            Edit the comment at the cursor in the same window. If
                        more than one comment covers the line, asks which
                        one.

                                                              *:CommentDelete*
:CommentDelete          Delete the comment at the cursor. If more than one
                        comment covers the line, asks which one. On a line
                        with no comment, lists the buffer's orphaned comments
                        to choose from.

                                                                *:CommentList*
:CommentList            Put every comment in the |quickfix| list and open it.
                        Any quickfix front-end (trouble.nvim, nvim-bqf,
                        Snacks.picker.qflist, :Telescope quickfix) can show
                        it.

                                                              *:CommentExport*
:CommentExport[!] [format]
                        Copy all comments to the system clipboard as
                        "markdown" (the default) or "json".
                        With [!], open them in a scratch buffer instead. From
                        there you can save them with |:w|, pipe them to a
                        command with |:w_c|, or filter them with |:range!|.

                                                              *:CommentToggle*
:CommentToggle [on|off] Show or hide the comment signs, or toggle them with no
                        argument. The comments stay and keep following your
                        edits.

                                                               *:CommentClear*
:CommentClear           Delete every comment.

==============================================================================
3. ANCHORS                                         *scratch-comments-anchors*

A comment belongs to a file and a range of lines.

- Commenting on the same lines again edits that comment.
- Commenting on different lines adds a new comment, even if the lines overlap
  another comment. A comment on lines 10-30 and one on line 14 are separate.

==============================================================================
4. RETENTION                                     *scratch-comments-retention*

Comments go away when the buffer is deleted (|:bdelete|, |:bwipeout|) or when
you run |:CommentClear|. Exporting leaves them in place, so you can export as
often as you like. To keep comments, save an export to a file.

If you delete all the lines a comment is on, the comment becomes an orphan.
Orphans are listed last in |:CommentList| and in an "Orphaned" section of the
export, and |undo| restores them. To delete one, run |:CommentDelete| on a
line with no comment.

In tmux you may need to set the clipboard to OSC 52 yourself: >lua
    vim.g.clipboard = "osc52"
<See |clipboard-osc52|.

==============================================================================
5. SIGNS                                             *scratch-comments-signs*

Each commented line gets a sign: "│" for a one-line comment, and "╭", "│", "╰"
down a range. The signs share the column with plugins like gitsigns and can
cover their signs; |:CommentToggle| hides ours when you need to see theirs.

                                                         *ScratchCommentSign*
The signs use ScratchCommentSign, which links to |hl-Todo|. To change it: >lua
    vim.api.nvim_set_hl(0, "ScratchCommentSign", {
      fg = "#2fafff",
      bg = "#004065",
    })
<

==============================================================================
6. LUA API                                             *scratch-comments-api*

>lua
    local scratch = require("scratch_comments")

    scratch.setup()
    scratch.add(start_line, end_line)  -- default: the cursor line
    scratch.show()
    scratch.edit()
    scratch.delete()
    scratch.list()
    scratch.render(format)             -- "markdown" (default) or "json"
    scratch.export(format, in_buffer)  -- copy, or open in a scratch buffer
    scratch.toggle(on)                 -- true, false, or nil to toggle
    scratch.clear()
<
Example mappings: >lua
    vim.keymap.set("n", "<leader>ca", "<Cmd>Comment<CR>")
    vim.keymap.set("x", "<leader>ca", ":Comment<CR>")
    vim.keymap.set("n", "<leader>cs", "<Cmd>CommentShow<CR>")
    vim.keymap.set("n", "<leader>cx", "<Cmd>CommentExport<CR>")
<

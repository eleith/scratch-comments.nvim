1. INTRODUCTION                               *scratch-comments-introduction*

Leave comments on lines in any file you are reading, then copy them all out as
Markdown to paste into an LLM or hand to a person. Commented lines are
highlighted; |:CommentShow| reads the comments on the cursor line.

Comments are scratch. They live in the buffer, are never written to disk, and
go away when you close the buffer or clear them.

Setup takes no options: >lua
    require("scratch_comments").setup()
<
This plugin sets no mappings. See |scratch-comments-api| to make your own.

==============================================================================
2. COMMANDS                                       *scratch-comments-commands*

                                                                    *:Comment*
:[range]Comment         Comment on the current line, or on [range]. If a
                        comment already exists on that exact anchor, edit it.

                                                                *:CommentShow*
:CommentShow            Show every comment on the cursor line in a float. It
                        closes when the cursor moves.

                                                                *:CommentEdit*
:CommentEdit            Edit the comment at the cursor. Prompts when more than
                        one anchor covers the cursor line.

                                                              *:CommentDelete*
:CommentDelete          Delete the comment at the cursor. Prompts when more
                        than one anchor covers the cursor line. On a line with
                        no comment, offers the buffer's orphaned comments.

                                                                *:CommentList*
:CommentList            Put every comment in the |quickfix| list and open it.
                        Any quickfix front-end (trouble.nvim, nvim-bqf,
                        Snacks.picker.qflist, :Telescope quickfix) can show
                        it.

                                                              *:CommentExport*
:CommentExport          Copy all comments to the system clipboard as Markdown.
                        Never clears; see |:CommentClear|.

                                                               *:CommentClear*
:CommentClear           Delete every comment.

==============================================================================
3. ANCHORS                                         *scratch-comments-anchors*

A comment is anchored to a file and a line range.

- Commenting on an anchor that already has a comment edits that comment.
- Commenting on a different anchor adds a new comment, including anchors that
  overlap or nest. A comment on lines 10-30 and one on line 14 are separate.

==============================================================================
4. RETENTION                                     *scratch-comments-retention*

Comments are lost when the buffer is wiped (|:bwipeout|) or |:CommentClear|
runs. Nothing else removes them. |:CommentExport| copies but never clears, so
you may export as many times as you like.

Deleting every line a comment covers orphans it. An orphan is hidden but kept:
|:CommentList| shows it last, |:CommentExport| lists it in an "Orphaned"
section, and |undo| restores it. Delete one with |:CommentDelete| from a line
with no comment.

There is no persistence and no state file. To keep comments, paste an export
into a file you own.

==============================================================================
5. HIGHLIGHT                                     *scratch-comments-highlight*

                                                        *ScratchCommentRange*
Commented lines use ScratchCommentRange, linked to |hl-Visual| by default.
Restyle it: >lua
    vim.api.nvim_set_hl(0, "ScratchCommentRange", { bg = "#3b3520" })
<

==============================================================================
6. LUA API                                             *scratch-comments-api*

>lua
    local scratch = require("scratch_comments")

    scratch.setup()
    scratch.add()         -- current line or command range
    scratch.add_visual()  -- visual selection
    scratch.show()
    scratch.edit()
    scratch.delete()
    scratch.list()
    scratch.render()      -- Markdown string for all comments
    scratch.export()      -- render and copy to the clipboard
    scratch.clear()
<
Example mappings: >lua
    vim.keymap.set("n", "<leader>ca", "<Cmd>Comment<CR>")
    vim.keymap.set("x", "<leader>ca", ":Comment<CR>")
    vim.keymap.set("n", "<leader>cs", "<Cmd>CommentShow<CR>")
    vim.keymap.set("n", "<leader>cx", "<Cmd>CommentExport<CR>")
<
